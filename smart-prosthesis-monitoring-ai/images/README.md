# Supporting Images

The original thesis figures (system architecture, sensor diagrams, algorithm
flowcharts) live in [`../docs/images/`](../docs/images/), and the AI
results screenshots live in [`../results/`](../results/) — both extracted
directly from the original thesis PDF, unaltered.

This folder is left available for additional polished/cleaned-up versions of the
system diagrams (e.g. a redrawn architecture SVG) if you want to create your own
for a portfolio site or slide deck, separate from the original thesis scans.
