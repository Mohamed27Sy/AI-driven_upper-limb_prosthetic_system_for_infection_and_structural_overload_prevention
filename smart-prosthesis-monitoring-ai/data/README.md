# Data

**No real patient data is included in this repository** — the original thesis
work did not export a patient database, and none would be shared here even if it
existed (biometric/health data). This folder documents the schema the system is
designed around and holds the synthetic data generated by `ai/01_data_exploration.ipynb`
onward, used to demonstrate the pipeline.

## Schema — raw load log

| Column | Type | Description |
|---|---|---|
| `timestamp` | datetime | When the reading was taken |
| `day_of_week` | string | Day name, for routine/pattern detection |
| `unit_location` | int | Location unit ID (e.g. 1 = Home, 2 = Work, 3 = Supermarket) |
| `applied_load_kg` | float | Load reading from the strain-gauge sensor, in kg |

## Schema — pH log (design, not yet simulated in the notebooks)

| Column | Type | Description |
|---|---|---|
| `timestamp` | datetime | When the reading was taken |
| `ph_value` | float | IrO₂ sensor pH reading |

## Generated files (from `ai/`)

- `synthetic_load_log.csv` — raw synthetic log (notebook 01)
- `intervals.csv` — 10-second interval segments (notebook 02)
- `features.csv` — per-day features + Safe/Risk labels (notebook 03)

These are regenerated each time the notebooks are re-run and are safe to delete.
